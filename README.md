# 100 Days of Python

My progress working through **"100 Days of Code: The Complete Python Pro Bootcamp"** on Udemy, taught by Angela Yu.

## Structure

```
100-days-of-python/
  Day_1/
  Day_2/
  ...
  Day_100/
  Projects/
```

- Each `Day_X` folder holds the code for that day's lesson/exercise
- `Projects/` holds standalone copies of the bigger projects from the course — some of these also get their own dedicated repo if I want to show them off properly

## About

I'm a Year 8 student teaching myself Python. This repo is where I'm tracking that progress, day by day, as I go.
